# VR_Test 🎮

Unity 기반 VR 게임 개발을 위한 기초 프로젝트 세팅 (Test)

## ✅ 주요 내용
- Unity XR Plugin Management 설정 완료
- OpenXR 기반 XR 환경 구성
- XR Interaction Toolkit 및 기본 입력 세팅 적용
- 기본 XR Origin (Camera Rig) 세팅 완료

## 🛠️ 개발 환경
- Unity 2022.3.45 LTS
- XR Interaction Toolkit
- OpenXR Plugin
- Oculus/Meta Quest 지원

## 📁 프로젝트 구성
- `Assets/`: 커스텀 에셋과 스크립트 추가 예정
- `Packages/`: XR 관련 패키지 포함
- `ProjectSettings/`: VR 빌드 및 입력 설정 포함

## 🚀 사용 방법
1. Unity Hub를 통해 프로젝트 열기
2. OpenXR 설정 및 연결된 HMD 기기에서 실행 테스트
3. 필요에 따라 XR Origin에 상호작용 오브젝트 추가
